Audit this repository's `CLAUDE.md`.

**Part 1 — what does not earn its place.** For each line or bullet, mark it
KEEP or CUT and justify in five words or fewer. CUT anything you would have done
anyway without being told. A CLAUDE.md costs tokens on every single call, and
restating the obvious buries the three lines that actually matter.

**Part 2 — what is missing.** List only things you had to guess about this
repository that changed what you wrote or would have written. Not things that
would be nice to document — things that misled you.

**Part 3 — the test.** For each KEEP line, name the specific wrong thing it
prevents. If you cannot name one, move it to CUT.

Output a short table, then the rewritten file. Do not write the file — show it.
