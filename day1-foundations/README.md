# Day 1 — Agentic AI Foundations

Get to a working agent quickly. Enough concept to design one properly, then
straight into building a tool-using agent from first principles.

| Lab | What | Time | Cost |
|---|---|---|---|
| [1.1](lab1-bare-metal-loop/README.md) | Build an agent loop from scratch, three tools, full tracing | 60 min | ~$0.02 |
| [1.2](lab2-tool-schema-clinic/README.md) | Tool schema clinic — measure what a description is worth | 30 min | ~$0.12 |
| [1.3](lab3-failure-gallery/README.md) | Five classic agent failures, reproduced and fixed | 30 min | free |

Start with 1.1. It is the session everything else in the programme rests on.

## Before you start

```bash
make doctor
```

## End-of-day checkpoint

See [CHECKPOINT.md](CHECKPOINT.md). You demonstrate a working, traced agent loop
